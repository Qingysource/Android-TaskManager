# CPUNAME.txt —— SoC 型号到商品展示名的对照表
#
# 格式：一行一条，第一列是型号（不分大小写），第一个空格之后的整段都是展示名。
#       # 开头是注释，空行忽略，UTF-8 编码。
# 维护：只加核实过的对应关系。型号与商品名对不上，比显示型号更糟。
# 加新平台不用改代码，追加一行就行。
#
# 匹配规则是**整词优先、前缀兜底**（都只忽略大小写），所以不要写 "mt6899*" 这种通配：
#   1) 型号整词相等，直接用这一条；
#   2) 设备报的型号带变体尾巴时（MT6833V/NZA、MT6877V/TTZA、MT6899Z/ZA），
#      取库里最长的那个前缀来认（MT6833 / MT6877 / MT6899）；
#   3) 数字尾巴不算变体，别指望 MT6833 吃掉一个并不存在的 MT6833x。
#
# 一个代号被多个商品名共用时（联发科很常见），取**最早上市/最常见**的那个名字，
# 并在该行注释里写明还对应哪些名字 —— 宁可名字偏旧，也不要写错产品线。
